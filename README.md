# جدول النقاط | Excel للأساتذة (PWA)

تطبيق ويب تقدمي (Progressive Web App) للأساتذة لإدارة قوائم التلاميذ وحساب النقاط والمعدلات الفصلية تلقائياً، مع دعم المسح الضوئي بالكاميرا (OCR) والإملاء الصوتي والتكامل مع منصة الرقمنة لوزارة التربية الوطنية.

## 🚀 كيفية تشغيل وتصدير التطبيق عبر GitHub مجاناً:

### الخطوة 1: رفع المشروع إلى مستودع جديد على GitHub
1. افتح حسابك على [GitHub](https://github.com) وأنشئ مستودعاً جديداً (New Repository) باسم مثلاً: `jadwel-niqat` واجعله **Public**.
2. ارفع الملفات الموجودة في هذا المجلد إلى المستودع:
   - `index.html`
   - `manifest.json`
   - `sw.js`
   - `icon-192.png`
   - `icon-512.png`

### الخطوة 2: تشغيل التطبيق عبر GitHub Pages (رابط HTTPS مجاني)
1. من صفحة المستودع على GitHub، اذهب إلى **Settings** > **Pages** (في القائمة الجانبية).
2. تحت قسم **Build and deployment**، اختر:
   - **Source:** Deploy from a branch
   - **Branch:** `main` (أو `master`) والمجلد `/ (root)`.
3. اضغط **Save**، وخلال دقيقة سيظهر لك رابط التطبيق الحي:
   `https://<username>.github.io/jadwel-niqat/`

---

## 📱 كيف تثبته كتطبيق على الهاتف وتحوله إلى APK:

### الطريقة الأولى: تثبيت PWA مباشر (بدون متجر وبدون إنترنت)
1. افتح رابط GitHub Pages على هاتفك (Chrome أو Edge).
2. اضغط على قائمة المتصفح (⋮) واختر **«إضافة إلى الشاشة الرئيسية»** (Install App / Add to Home screen).
3. سيظهر التطبيق كأيقونة مستقلة كاملة الشاشة ويعمل حتى بدون اتصال بالإنترنت.

### الطريقة الثانية: تحميل ملف APK للأندرويد عبر PWABuilder
1. ادخل إلى موقع مايكروسوفت الرسمي: [PWABuilder.com](https://www.pwabuilder.com/)
2. الصق رابط موقعك على GitHub Pages واضغط **Start**.
3. اضغط **Package for Stores** ثم اختر **Android (APK)**.
4. حمّل ملف الـ APK وثبّته مباشرة على أي هاتف أندرويد.
